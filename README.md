# Tape Gembong Bu Endang

Website landing page responsive untuk Tape Gembong Bu Endang.

## Teknologi
- HTML5
- CSS3
- Bootstrap 5.3
- Bootstrap Icons
- JavaScript vanilla

## Struktur
- `index.html` — halaman utama
- `css/style.css` — styling
- `js/script.js` — interaksi/navbar/WhatsApp
- `assets/` — gambar produk dari materi yang diberikan

## Cara menjalankan
Tidak perlu server. Cukup buka `index.html` di browser.

Untuk pengalaman development, bisa memakai Live Server di VS Code.
